# Block Forge: Kingdom (قلعة البلوكات)

لعبة ألغاز **Hybrid-Casual** بأسلوب وضع البلوكات (8×8) مع خريطة مغامرة من 30 مرحلة، نظام تطوير المملكة، مهام يومية، وأدوات مساعدة (قنبلة 3×3، مطرقة، تبديل).

## المزايا الرئيسية
- **الوضع الكلاسيكي (Classic Mode):** لعب لا نهائي مع نظام مضاعفات الكومبو وحفظ أعلى سكور.
- **خريطة المغامرة (30 مرحلة):** أهداف متنوعة (النقاط، جمع الجواهر، كسر عقبات الجليد).
- **بناء المملكة (Kingdom Builder):** ترقية 4 معالم تمنح مزايا دائمة داخل اللعب.
- **ثنائية اللغة:** دعم كامل للعربية (RTL) والإنجليزية (LTR).

## البناء التلقائي عبر GitHub Actions
يتم بناء نسخ الأندرويد تلقائياً على السحابة عبر `.github/workflows/build_android.yml`:
1. كل `push` على فرع `main` يشغل `flutter analyze` و `flutter test` ثم يبني:
   - `app-release.apk` (للتثبيت المباشر على الموبايل)
   - `app-release.aab` (للرفع على Google Play)
2. لتحميل الملفات من GitHub: افتح تبويب **Actions** -> اختر آخر Build ناجح -> قسم **Artifacts**.

### توقيع نسخة النشر الرسمية على جوجل بلاي (اختياري عبر Secrets)
لإخراج `.aab` موقّع بمفتاح الرفع الرسمي الخاص بك، أضف هذه المتغيرات في **Settings -> Secrets and variables -> Actions**:
- `ANDROID_KEYSTORE_BASE64`: محتوى ملف `.jks` محوّلاً إلى Base64
- `ANDROID_KEY_ALIAS`: اسم الـ Alias
- `ANDROID_KEY_PASSWORD`: كلمة مرور المفتاح
- `ANDROID_STORE_PASSWORD`: كلمة مرور الـ Keystore
